# TALERA V12 — uniform scherp fotovlak

De presentatie gebruikt één scherpe, volledige foto zonder dynamische maskers, dubbele fotolagen of witte waas. Alleen onderaan is een zachte donkere tekstgradient zichtbaar.

Deze wijziging zit uitsluitend in de bestaande presentatieadapter, geen nieuwe fotosorteerder, tijdlijn, recorder of presentatiemotor. Persoonlijke herinneringen en de 50 testfoto's blijven ongewijzigd. Bij liggende foto's kiest `object-fit: cover` voor een middenuitsnede; die afweging moet expliciet op iPhone beoordeeld worden.

Bronbestand: `presentation-photo-v12.css`. De oude V11 Raw/A-B-modus is in deze testkandidaat uitgeschakeld zodat `photo_test=raw` geen onverwachte andere foto's oproept.

**V12 is een testversie, niet automatisch goedgekeurd.**
